# Security policy

## Supported versions

Security fixes are released for the latest published version on Maven Central.

## Reporting a vulnerability

Report vulnerabilities privately through **Report a vulnerability** on the repository's [Security tab](https://github.com/it-atelier-gn/loadshift-kotlin/security). Please do not open a public issue for a vulnerability.

Once a fix is available, it is published as a new version and described in its release notes.
